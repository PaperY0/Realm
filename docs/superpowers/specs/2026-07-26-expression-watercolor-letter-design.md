# 风铃入口水彩信纸视觉修正设计

## 目标

让风铃入口/表达页直接呈现参照图二、图三的手绘水彩背景、柔和配色、纸张纹理与不规则边缘，同时保留现有表达、追问、寄出和纸船流程。

## 方案

- 桌面端以现有 `src/assets/expression-watercolor-reference.png` 作为完整视觉构图基准，避免用渐变近似水彩与纸张。
- 将表达页内容层设为透明，仅保留布局、文字、输入框和按钮的交互职责；内容容器与复合参考图中的纸张区域对齐。
- 删除/覆盖此前多轮表达页背景模拟规则，避免 CSS 规则顺序继续互相覆盖。
- 移动端使用同一水彩素材作为底图，并将内容恢复为可滚动的纸张内布局，确保 textarea、按钮和辅助文案不被裁切。
- 不修改表达数据流、隐私处理、安全拦截或纸船生成逻辑。

## 验收标准

1. 桌面端首屏可见明显的紫、粉、橙、黄、绿水彩晕染，颜色与参照图一致。
2. 中央纸张具有真实的暖白纸纹、手绘不规则边缘和阴影，不再呈现规则圆角卡片。
3. 标题、引用、演示句、textarea、按钮均落在纸张内容区域内，交互可用。
4. 375px 左右小屏无横向滚动，文字和主要操作不被遮挡。
5. 现有表达页相关测试与页面脚本检查通过。
