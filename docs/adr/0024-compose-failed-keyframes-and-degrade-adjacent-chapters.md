# 单张关键帧失败后使用组合关键帧并降级相邻章节

K0–K7 中任意一张边界关键帧生成失败时，只重试该张一次，不重新生成全部关键帧。第二次仍失败，则使用预先验收的透明背景守门 IP 素材、对应模板场景以及本次故事的颜色、信物和象征元素，确定性地合成 `composed_keyframe`。

组合关键帧不是通用占位图，但不再提交给视频模型。凡是以该图作为起始帧或结束帧的相邻章节，直接采用网页个性化降级版本；其他边界关键帧正常的章节继续生成完整视频。

该选择需要提前准备可组合的 IP 与模板场景素材，并放弃受影响章节的完整视频，以避免单张图片故障阻断整本书，也避免把明显不同的合成图交给视频模型后扩大视觉跳变。
