# V0 通过一个统一模型网关接入多模态模型

V0 只集成一个外部模型中转站，并使用一个 API Key。故事工作流只依赖一个统一网关适配层，但适配层内部按模态配置两个物理地址：文本模型使用 `TEXT_BASE_URL`，图像与视频模型使用 `MEDIA_BASE_URL`。应用不分别管理多个上游供应商的账号和密钥。

中转站只是统一模型网关，不被视为一个具体模型。系统仍需要记录每个任务所指定及实际返回的上游模型、模型版本和任务编号。此前确定的数据最小化、禁止训练、最长 30 天保留及删除要求，同时适用于中转站和其上游处理方。

物理地址必须通过环境配置提供，不在代码中硬编码。该选择降低 72 小时 V0 的接入和密钥管理成本，同时适应该中转站按模态拆分接口地址的现实；代价是形成对单一网关可用性、接口兼容性和数据政策的依赖。网关不可用时使用个性化降级版本，不在 V0 中接入第二套网关。
