# 动态图片生成规格提示词设计

## 目标

让发送给图片模型的提示词明确包含本次请求实际使用的输出规格，并保证提示词与 API 请求字段来自同一份运行时配置。

## 方案

`buildImagePrompt` 接收可选的渲染规格，动态拼接像素尺寸、宽高比、输出格式和单图约束。`readConfiguration` 先规范化 `size` 与 `outputFormat`，再用它们构建提示词和请求配置。

默认行为继续使用 `720x1280` 与 PNG；现有风格权威块、故事变量、图片响应校验、重试和 fallback 行为不变。

## 验收

- 默认提示词包含 `720x1280`、`9:16`、`PNG` 和禁止文字/水印等约束。
- 自定义运行时尺寸会同时出现在提示词和请求字段中。
- 图像相关测试、语法检查通过。
