# 藏梦书境 V0 媒体规格

## 适用范围

本规格是 Windows 单机比赛 Demo 的统一媒体合同，适用于 K0–K7 边界关键帧、七个正式章节视频、服务端转码产物及个性化网页降级。它不定义未来移动端或生产环境的交付规格。

## 演示与验收环境

| 项目 | V0 规格 |
|---|---|
| 演示系统 | Windows |
| 演示浏览器 | Chrome / Edge 全屏 |
| 基准验收视口 | 1920×1080 |
| 兼容桌面视口 | 1366×768 等比缩小，核心布局与操作完整 |
| 手机和平板 | 只要求不崩溃，不作为视觉验收目标 |

## 画面合同

- 绘本章节统一使用 16:9 容器。
- K0–K7 正式关键帧成品尺寸为 1280×720。
- 正式章节视频成品尺寸为 1280×720。
- 主角、信物、主要动作和关键象征必须落在安全构图区内；边缘只放允许裁切或弱化的环境信息。
- 完整章节视频和 `dynamic_fallback` 必须占用相同的画面容器，切换媒介类型时不得导致版式跳动。
- 网页不展示浏览器原生视频控件；播放、停止、下一章与静音由绘本界面统一控制。

## 正式章节视频合同

| 项目 | V0 规格 |
|---|---|
| 时长 | 约 5 秒 |
| 镜头结构 | 单一连续镜头，禁止内部切镜 |
| 主要动作 | 1 个 |
| 主要镜头运动 | 最多 1 次 |
| 分辨率 | 1280×720 |
| 帧率 | 24 fps |
| 容器 | MP4 |
| 视频编码 | H.264 |
| 像素格式 | yuv420p |
| 音轨 | 无 |
| 结尾 | 稳定停在本章结束边界关键帧 |

## 服务端标准化

- 供应商返回的媒体不得直接作为网页正式资产。
- 服务端使用 FFmpeg 将视频统一标准化为 1280×720、24 fps、MP4 / H.264 / yuv420p，并移除所有音轨。
- 标准化后必须执行确定性技术检查，再进入独立视觉语义检查。
- 无法成功解码、尺寸或时长严重不符、存在意外音轨、标准化失败的文件属于媒体硬失败，按已确认的单章重试或网页降级规则处理。
- FFmpeg 标准化只处理技术格式，不得通过裁切破坏首尾帧、守门 IP、信物、主要动作或安全构图。

## 网页降级一致性

- `dynamic_fallback` 以本章真实起止边界关键帧构成约 5 秒动画。
- 推镜、横移、光影和粒子效果在同一个 16:9、1280×720 逻辑画布中编排，并随网页容器等比缩放。
- 降级章节使用与正式视频相同的网页正文、环境音乐和 UI 音效层，但不得标记或伪装为正式 AI 视频。
