# 允许受准入条件约束的第三方 AI 生成服务

V0 可以通过正式 API 使用第三方文本、图像和视频模型，但供应商只能收到经过安全处理且按任务进一步裁剪的必要输入，不能收到用户原始表达。供应商不得使用请求内容训练模型，内容保留期不得超过 30 天，并应在可用时优先启用零数据保留模式。

系统记录供应商、模型版本和任务编号以支持追踪与删除，但记录中不保存用户原文。供应商模型只执行受约束的规划或渲染任务，更换模型不能获得修改已冻结故事事实的权限。产品隐私说明必须明确披露经过处理的故事信息会被发送给第三方 AI 服务商。

该选择接受受控的外部数据处理风险，以换取 V0 能够实际完成七章并行生成；声音按 ADR 0030 使用本地素材，不调用音频模型；完全自托管当前会显著增加模型部署、视频生成和运维成本。
