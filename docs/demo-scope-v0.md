# 藏梦书境 V0 比赛 Demo 范围

## 目标

在一台 Windows 演示电脑上，通过真实文本和图像模型调用、本地 2.5D 动效，以及按章可选的真实视频增强，完成“一次用户经历生成一本七章个性化绘本并逐章阅读”的端到端证明。当前交付不以正式上线、多人试用、多册经营或商业运营为目标。

## 必须真实运行

- 用户先看到世界大门静态场景，明确点击大门后播放本地入场视频；视频结束时渐渐变黑，再淡入内耗之门，不把旅人初页作为当前演示前置页面。
- 世界主 IP 在世界大门与内耗之门之间完成视觉交接；门厅只开放内耗之门，不提供多情绪世界选择。
- 用户沿内耗世界固定路径抵达风铃入口，使用文字表达或选择“我还不知道怎么说”。
- 表达前可选本次会话需求：“陪我待一会 / 帮我理一理 / 给我一点勇气 / 先留下来”；它只调整题记和合书后回应语气，不改变七章剧情，也不进入永久人格画像。
- 内耗守门 IP 最多进行两次自然追问，每次只补一项故事必需信息，任意一次都可跳过，不展示心理标签或诊断结论。
- 用户确认后进入纸船生成仪式；等待期间持续展示纸船、雾、标题、角色剪影或首张画面等世界反馈，不出现只有转圈图标的空白页。
- 文本工作流真实生成 SafeStoryBrief、StoryTemplateMatch、StoryBible、StorybookStyleGuide、ChapterIllustrationPlan 和七张 ChapterCard。
- 故事包通过结构与叙事语义验收后，`image_selector` 并行生成七张章节主插画。
- 演示者在进入动画前人工审核七张插画；未通过的章节只重做该章。
- 本地 `storybook_motion` 并行制作七个 5～8 秒、9:16、720×1280 的 2.5D 动态预览。
- 七章本地预览全部可播放后才能开书；用户主动进入每章，媒体结束后停住并等待“下一章”，不自动播放下一章。
- 每章最多设置一个非分支式视觉互动点；它只让画面或声音回应用户，不改变故事事实、章节顺序或后续剧情。
- 演示者可逐章批准 `video_selector` 提交 Seedance 真实动态增强；未批准、生成慢或失败时继续使用本地预览。
- 最后一章结束后支持主动合书，当前书进入回声书架并留下信物与环境变化；守门 IP 可依据本次会话需求给出有限的地点相关短回应。
- 页面刷新或再次进入后能够恢复当前这一本书的故事包、媒体任务、阅读/合书状态、信物和环境变化，并支持重读。
- 提供一键重置，清理当前书、运行状态和本地临时媒体；只有重置后才能讲述新经历并生成新书。

## 运行边界

- V0 只展示内耗世界；门厅只有唯一开放的内耗之门，不展示其他情绪世界入口或多世界选择页。
- 标签卷与回声卷只做内部路由，页面不提供选卷入口。
- 一次只运行一个浏览器演示会话，一次只生成并保存当前一本书。
- 再次进入只能继续或重读当前书，不支持保留旧书后生成多册或“下一册”；新经历必须先重置当前书。
- 服务端、SQLite 和媒体资产都位于演示电脑。
- 演示使用真实网络与真实中转站 API，不以预生成素材冒充本次输入结果。
- 默认媒体是本地 2.5D 绘本动态，不做 3D 角色动画，也不要求默认生成七章 Seedance 视频。

## 演示终端与视觉验收

- 唯一正式演示与视觉验收环境为 Windows 上的 Chrome 或 Edge 全屏窗口。
- 基准验收视口为 1920×1080；1366×768 只要求布局完整且核心操作可用。
- 手机和平板不是本次视觉验收目标，只要求页面能够打开、不会崩溃。
- 用户不阅读说明也应能在 10 秒内理解需要点击世界大门；世界大门视频入口提供减少动态效果，视频失败时直接进入内耗之门。
- 本地动态预览和可选增强共用同一个 9:16 绘本画面容器，不显示浏览器原生视频控件。
- 守门 IP、信物、主要动作和重要视觉信息必须位于安全构图区。

## 本地状态与媒体存储

- 使用单个本地 SQLite 数据库保存当前绘本、文本规划、插画任务、插画审核、动效任务、可选增强任务、验收结果、阅读/合书状态、信物和环境变化。
- SQLite 只保存状态、标识符、必要元数据和相对文件路径，不把图片或视频保存为数据库 BLOB。
- 插画、2.5D 预览、可选增强和临时文件保存在当前 bookId 对应的本地媒体目录。
- 七个章节分别更新自己的数据库记录，避免多个异步任务共同覆盖一个 JSON 状态文件。
- 一键重置清除当前书的数据库记录与媒体目录，不影响应用内置的世界主 IP、内耗守门 IP、风格参考和故事模板。
- V0 不建设多书 SQLite 模型、历史书架管理或多册持久化。

## 声音与文字层

- 本次不调用音频模型，不生成 AI 旁白、角色对白、口型同步或个性化音乐。
- 忽略或移除可选增强返回的原始音轨。
- 使用一条本地预置的轻柔环境音乐，以及少量推门、风铃、翻页和合书 UI 音效。
- 声音在用户首次主动交互后才开始，并始终提供可发现的静音开关。
- 每章正文由网页 DOM 文字层呈现，不烧录进媒体；文字可随画面渐显，并在媒体停止后继续保留。

## 本次不实现

- 公网部署、域名、TLS 和生产运维。
- 注册、登录、账户找回和跨设备同步。
- 多册绘本、历史书库、多书架管理，以及不重置当前书直接生成下一册。
- 多用户并发、水平扩容、分布式锁、Redis、消息队列、云对象存储和 CDN。
- 生产级监控、告警、审计后台和运营后台。
- 支付、订阅、额度购买和商业化功能。
- 影响剧情的选择、分支叙事、对错选项和互动游戏关卡。
- 3D 建模、角色绑定、完整角色表演和默认七章视频模型生成。
- 三十天服务端留存的生产定时清理任务。

## 保留但不作为 Demo 验收项

之前确认的隐私边界、三十天资产留存、主动删除和正式危机资源策略继续作为未来产品约束保留，但本次只实现与单机 Demo 直接相关的最小删除、安全和密钥保护能力。
