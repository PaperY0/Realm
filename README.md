# 藏梦书境

> 一个把心事写成童话的 Web 世界。

《藏梦书境》当前是 **Web-only** 的 Windows 本机单实例 Demo。现阶段已经走通世界大门视频入场、内耗之门、表达与安全故事摘要，并接入服务端 `gpt-image-2` 单图生成网关；完整七章绘本闭环仍是后续目标，不应把当前 Demo 描述成已经完成整书生成与阅读。

## 当前真实状态

### 已实现

- Web 端世界大门点击入场视频、唯一开放的内耗之门和表达页。
- 文字表达、固定演示句和“我还不知道怎么说”。
- 最多两次、每次可跳过的追问。
- 浏览器内高风险关键词拦截：命中后清除临时内容，不创建 SafeStoryBrief，也不发送图片生成请求。
- 从普通表达和追问答案构建并校验 SafeStoryBrief；形成摘要后清除页面中的原始表达和追问内容。
- 服务端 Image 2 单图网关：浏览器只提交 SafeStoryBrief，模型固定为 `gpt-image-2`，生成成功时只接受同源 PNG 结果。
- 真实链路探针：默认仅做零费用配置检查；只有显式确认命令才允许发送一次真实生成请求，无自动重试、无 fallback。
- 生成失败 UI 契约：明确显示“真实生成未完成”，不使用预制图或占位图冒充结果。

### 尚未验证

- **尚未获得并验收一张真实 `gpt-image-2` 成功生成图片。** 当前只能确认网关、请求约束、失败处理和探针已经实现，不能宣称真实生图链路成功。
- 当前实现与自动化检查不能替代完整的人工视觉验收、供应商联网验收或整书 E2E 验收。

### 尚未完成

- 完整七章故事包与恰好七张 ChapterCard。
- JSON Schema 结构门禁与独立叙事语义门禁组成的双重门禁闭环。
- 七张章节插画并行生成、逐章审核和单章重做。
- 七章本地 2.5D 正式媒体和完整互动绘本阅读器。
- 合书、信物反馈、世界变化、入架、恢复、重读与整书重置闭环。
- App/原生端不在当前开发范围内。

## 当前可演示路径

```text
世界大门
→ 点击大门播放入场视频
→ 黑场淡入
→ 内耗之门
→ 表达页
→ 最多两次追问
→ SafeStoryBrief
→ gpt-image-2 单图网关
→ 成功图片或明确失败状态
```

目前现场 Demo 应以 SafeStoryBrief 和真实网关调用契约为边界。若供应商返回失败，必须展示失败状态，不得切换到样片、预制结果或其他模型。

## V0 目标闭环

以下是后续目标，不代表当前已经实现：

1. 在 Chrome 或 Edge 全屏进入唯一开放的内耗世界。
2. 用户自然表达，可跳过最多两次追问；系统完成安全分流和隐私过滤。
3. 生成并校验 SafeStoryBrief、内部路由、故事事实、视觉合同与恰好七张 ChapterCard。
4. 并行生成七张 9:16 章节主插画并逐章审核；失败只重做对应章节。
5. 用审核通过的插画制作七章本地 2.5D 动态预览。
6. 七章资产通过双重门禁后进入真实翻书阅读。
7. 完成合书、信物、世界变化、入架、恢复、重读和一键重置。

## 运行与安全边界

- 仅支持 Web 端：本地浏览器 + 本地 Node.js 服务端。
- 一次只有一名用户、一个浏览器会话和一个当前生成流程。
- API Key 只能由服务端环境变量读取，不得进入浏览器代码、仓库、日志或错误响应。
- 浏览器不得把原始表达直接发送给图片服务，只能提交通过安全检查的 SafeStoryBrief。
- 不得用预生成故事、插画、占位图或 fallback 冒充本次真实生成结果。
- 当前没有生产部署、多用户并发、登录、云同步、支付或移动端完整适配。

## 当前可用命令

项目当前无第三方运行依赖，不需要执行 `npm install`。

```powershell
# 启动 Web Demo
npm start

# 浏览器打开
http://127.0.0.1:3000

# 运行当前自动化检查
npm test

# 运行 Demo 预检与语法检查
npm run demo:check

# Image 2 零费用配置检查：不发送生成请求
npm run image2:check

# 明确付费的一次真实生成探针：只在单独授权后执行
npm run image2:live
```

`npm run image2:live` 可能产生真实费用。失败时不自动重试、不切换模型、不使用 fallback；在成功图片经过实际检查前，项目状态必须保持“真实 `gpt-image-2` 成功图片尚未验证”。
