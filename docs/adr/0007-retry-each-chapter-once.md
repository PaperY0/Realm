# 每个章节视频最多自动重试一次

章节视频只有在出现明确失败时才自动重试：供应商返回失败、取消或无效终止状态，或者供应商生成成功但结果未通过角色、动作、边界帧、物件或场景质量验证。重试时可根据失败类型收紧对应约束，但不能改变冻结故事包。

`queued`、`pending` 和 `processing` 属于正常生成状态，不因经过固定的短时间而被判定失败，也不触发重复提交。第一章到达五分钟开书上限时可以先使用个性化降级版本，但仍在正常处理的原视频任务继续运行。

每章最多自动重试一次；第二次出现明确失败后使用同一故事与分镜的个性化降级版本。单章失败不触发整册重做，也不能改变总故事规划。V0 不另设整本书的视频提交总量上限，七章分别拥有自己的重试机会；该策略避免慢任务造成重复费用，同时保留每章一次有限的质量修复机会。
