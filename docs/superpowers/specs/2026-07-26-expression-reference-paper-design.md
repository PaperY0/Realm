# 风铃入口参考图信纸重设计

## 目标

仅重做“风铃入口/表达页”的视觉表现，使其在 1280×720 视口中接近用户提供的参考图：整屏水彩晕染背景，中间一张偏米白、带褶皱和折角的旧信纸，内容集中在信纸内部并保留现有表达流程。

## 视觉约束

- 背景使用蓝紫、粉珊瑚、暖黄、灰绿四组大面积不规则水彩晕染，不使用规整网格或玻璃拟态。
- 信纸宽度目标约为视口宽度的 72%，高度约为视口高度的 82%，最大约 920×596px。
- 信纸使用暖米白纸色、纤维纹理、两条低对比折痕、四角轻微缺口/折角和柔和的纸张投影。
- 内容不改变 DOM 交互、表单字段、生成流程和隐藏等待动画；仅调整表达页 CSS。
- 响应式视口下不产生横向滚动，窄屏保留同一构图语言但缩小留白。

## 实现策略

在现有 `src/index.html` 结构上，只修改 `src/styles.css` 的 expression stage 覆盖层。通过 CSS 多层 `radial-gradient`、`repeating-linear-gradient`、伪元素和 `clip-path` 实现水彩/纸张材质，不引入新依赖或外部图片资源。

## 验收标准

- expression stage 的页面结构和按钮行为不变。
- 1280×720 下纸张边界、比例和背景色块接近参考图。
- 390×844、820×720、1280×720 下表达页可见且 `scrollWidth === clientWidth`。
- 现有相关测试、`node --check src/app.js`、`git diff --check` 通过。
