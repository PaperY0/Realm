# V0 模型配置档案

> 状态：已锁定。模型通过统一中转服务和同一个服务端 API Key 调用；V0 不进行多模型定标或运行时自动切换模型名称。

## 接入边界

- `TEXT_BASE_URL`：`https://api.openai-next.com/v1`
- `MEDIA_BASE_URL`：`https://draw.openai-next.com`
- 认证：由同一个服务端环境变量提供 API Key，禁止进入浏览器包、数据库、日志或仓库。
- 浏览器只调用本地 Node.js 服务，不直接访问中转站。

## 固定模型

| 能力 | 配置项 | 模型 | V0 角色 |
|---|---|---|---|
| 文本 | `TEXT_MODEL` | `gpt-5.6-sol` | 生成和修复结构化故事包 |
| 图像 | `IMAGE_MODEL` | `gpt-image-2` | 生成七张章节主插画 |
| 视频 | `VIDEO_MODEL` | `doubao-seedance-2-0-fast-260128` | 逐章批准后的可选真实动态增强 |

## 文本模型准入要求

- SafeStoryBrief、StoryTemplateMatch、StoryBible、StorybookStyleGuide、ChapterIllustrationPlan 和 ChapterCard 必须通过应用层 JSON Schema 校验。
- 首次格式错误只允许一次不改变故事事实的受限修复。
- 叙事语义不合格只允许全局故事规划器完整重规划一次。
- 中转站是否原生支持严格结构化输出，不改变应用层校验责任。

## 图像模型准入要求

- 必须支持守门 IP 参考图和绘本风格参考输入。
- 七个章节任务都重新提供同一套 IP 参考资产、StorybookStyleGuide 和对应 ChapterCard 约束。
- 每章生成一张主插画，成品为竖屏 9:16、720×1280。
- 正式插画不得依赖纯文本角色描述维持身份，也不得内嵌字幕、水印或无关文字。
- 七张插画生成后必须逐章人工审核；未批准的插画不能进入本地 2.5D 动效制作。

## 本地 2.5D 动效要求

- `storybook_motion` 是默认正式媒体路径，不调用视频模型。
- 每章使用已审核主插画制作一个 5～8 秒动态预览。
- 输出统一为 720×1280、24 fps、MP4 / H.264 / yuv420p、无音轨。
- 每章最多一个主要镜头运动、二至三层视差和两个局部微动。
- 必须保留原插画的角色结构、构图、笔触和纹理；禁止 3D 建模、角色绑定、口型、完整走路或转身和明显画面扭曲。

## 视频模型准入要求

- Seedance 只用于逐章人工批准后的可选增强，不是可开书依赖。
- 必须支持以本章已审核主插画作为视觉参考或首帧提交任务。
- 任务提交、状态轮询、结果下载和终止失败格式必须通过真实探针确认。
- 供应商原始输出不得直接替换本地预览，必须先经过标准化和媒体验收。
- 生成慢、失败、停滞或质量不合格时，保留本章 `storybook_motion_preview`。

## 网页播放合同

- 本地预览和可选增强共用同一个 9:16 章节容器。
- 动态播放结束后停住，等待用户主动进入下一章。
- 不显示浏览器原生视频控件。
- 完整媒体技术合同见 `docs/media-profile-v0.md`。
