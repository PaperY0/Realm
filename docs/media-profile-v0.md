# 藏梦书境 V0 媒体规格

## 适用范围

本规格是 Windows 单机比赛 Demo 的统一媒体合同，适用于七张章节主插画、七章本地 2.5D 动态预览、可选 Seedance 真实动态增强和网页播放容器。它不定义未来移动端或生产环境的交付规格。

## 演示与验收环境

| 项目 | V0 规格 |
|---|---|
| 演示系统 | Windows |
| 演示浏览器 | Chrome / Edge 全屏 |
| 基准验收视口 | 1920×1080 |
| 兼容桌面视口 | 1366×768 等比适配，核心布局与操作完整 |
| 手机和平板 | 只要求不崩溃，不作为视觉验收目标 |

## 章节主插画合同

- 一本书固定生成七张章节主插画，每章一张，编号 `I1` 至 `I7`。
- 输出为竖屏 `9:16`、`720×1280`。
- 每张插画都必须使用同一套内耗守门 IP 参考资产，并遵守冻结的 StoryBible、StorybookStyleGuide、ChapterIllustrationPlan 和对应 ChapterCard。
- 连续性关注固定角色特征、服装、信物、反复象征、章节状态、色彩与光线递进；不要求相邻章节共享像素相同的首尾画面。
- 插画不得内嵌标题、正文、字幕、水印或无关文字；章节文字由网页 DOM 层呈现。
- 七张插画必须在进入本地动画前完成人工审核。审核失败的章节只重做该章插画，不影响已经通过的章节。

## 本地 2.5D 动态预览合同

| 项目 | V0 规格 |
|---|---|
| 角色 | 默认正式章节媒体，不是失败降级 |
| 时长 | 5～8 秒 |
| 画幅与尺寸 | 竖屏 9:16，720×1280 |
| 帧率 | 24 fps |
| 容器 | MP4 |
| 视频编码 | H.264 |
| 像素格式 | yuv420p |
| 音轨 | 无 |
| 内部切镜 | 禁止 |
| 主要镜头运动 | 最多 1 个 |
| 视差层级 | 2～3 层 |
| 局部微动 | 最多 2 个 |

允许的表现包括：

- 缓慢推近、拉远或单向平移；
- 二至三层景深视差；
- 轻微光影、雾气、雨雪或环境粒子；
- 呼吸、头发、衣角或信物的小幅微动。

禁止的表现包括：

- 3D 建模、角色绑定、塑料材质或三维旋转；
- 五官、表情或肢体结构变形；
- 口型、完整走路、完整转身或环绕镜头；
- 动画生成新人物、新道具、新剧情或改变章节事实；
- 明显拉伸、重绘或破坏原插画笔触、纹理和构图。

## 本地标准化与技术门禁

- `storybook_motion` 使用本地动效与 FFmpeg 流程生成章节预览，并统一输出为 720×1280、24 fps、MP4 / H.264 / yuv420p、无音轨。
- 标准化后至少检查文件可解码、画幅、尺寸、时长、帧率、编码、像素格式、音轨和明显黑帧。
- 技术门禁只处理客观可用性，不能替代章节插画的人工审核。
- 网页不展示浏览器原生视频控件；播放、重播、停止、下一章与静音由绘本界面统一控制。

## Seedance 可选增强

- Seedance 不属于开书必需链路，只用于演示者认为某章确实需要真实动态时的可选增强。
- 每章必须单独批准后，`video_selector` 才能提交该章任务；整本书不存在一次性批量批准。
- 生成任务以本章已审核主插画作为视觉参考或首帧，并继续遵守 ChapterCard 的事实、构图和禁止运动。
- 增强结果必须通过技术与视觉检查后才能替换本地预览。
- 生成慢、失败、质量不合格或未批准时，无条件保留本地 2.5D 动态预览；不得因此阻止开书或中断阅读。

## 网页展示一致性

- 本地预览和可选增强使用同一个 9:16 章节画面容器，替换媒体时不得导致布局跳动。
- 章节画面播放结束后停住，正文继续保留；只有用户主动点击“下一章”才推进。
- 章节之间通过网页翻页、光影和书页动画承接，不依赖共享边界帧制造连续性。
