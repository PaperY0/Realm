# 风铃入口手绘水彩纸张视觉改造

## 目标

只改造“风铃入口/表达页”的视觉表现，使其接近用户提供的手绘绘本参考图：纸张不再像规则的数字卡片，而是带有轻微褶皱、压痕、颗粒和水彩晕染；页面背景具有紫蓝、珊瑚橙、奶油黄的手绘天空氛围。

世界入口、情绪选择页、故事书页面、绘本翻页动画和生成流程逻辑保持不变。

## 视觉方案

采用 CSS 手绘纹理方案，不新增大体积背景图片。通过多层渐变、伪元素、低透明度纹理和局部阴影完成质感。

### 表达页背景

- 使用紫灰、珊瑚橙、奶油黄的非线性渐变，模拟参考图的水彩天空。
- 增加柔和的径向光晕、低对比度颗粒和不规则色块。
- 保留星星装饰，但降低几何感，使用柔和透明度和轻微旋转。
- 背景层只作用于 `.scene--expression`，不影响其他场景。

### 纸张

- 保留现有表达页结构和内容布局。
- 使用米白和暖黄色叠层，增加纸张纤维感、横向细纹和局部色彩晕染。
- 通过伪元素添加多条极淡的折痕/压痕，避免规则网格感。
- 纸张边缘使用轻微不对称阴影与柔和边缘变化，形成手工裁切感。
- 文本、输入框和按钮继续保持清晰可读，不使用强噪点覆盖文字。

## 交互与兼容性

- 不修改表达提交、演示句、追问和寄出信件的行为。
- 不恢复已隐藏的纸船等待动画或生成过程卡片。
- 维持表达页一屏布局，不新增页面滚动。
- 保持窄屏媒体查询，必要时只调整视觉层的透明度和纹理强度。

## 验收标准

1. 浏览器进入 `expression` 场景后，只有表达页呈现新背景与纸张质感。
2. 桌面 1280×720 下，纸张边缘、折痕、颗粒和水彩背景均可辨识，但不影响文字阅读。
3. `document.documentElement.scrollHeight` 与 `clientHeight` 相等，页面不出现滚动条。
4. 窄屏下内容不横向溢出，按钮和输入区域仍可操作。
5. 既有全量测试与表达页静态测试继续通过。
