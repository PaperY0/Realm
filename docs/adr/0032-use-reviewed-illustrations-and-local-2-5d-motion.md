# 使用七张审核插画和本地 2.5D 动效作为默认媒体

## 背景

默认并行生成七章 Seedance 视频会把比赛 Demo 的主要等待时间和失败风险交给外部视频任务；K0–K7 共享边界帧、首尾帧约束和网页降级同时增加了媒体合同、重试路径与验收复杂度。更重要的是，低质量 3D 建模、穿模、塑料材质和角色绑定会破坏参考图原有的绘本质感。

## 决策

V0 的正式媒体主链路改为：

```text
七章剧本 + StoryBible + StorybookStyleGuide
→ 审核七章分镜与章节插画计划
→ image_selector 并行生成七张章节主插画
→ 演示者人工审核七张插画
→ storybook_motion 本地并行制作七章 2.5D 动态预览
→ 七个 9:16、720×1280、5～8 秒的正式章节资产
→ 演示者按章判断是否需要真实动态
→ 只有逐章明确批准后，video_selector 才向 Seedance 提交该章增强任务
```

每章只有一张主插画。七张主插画完全取代 K0–K7 八张共享边界关键帧；相邻章节不再要求共享像素完全相同的首尾边界。跨章连续性由同一套守门 IP 参考图、StoryBible、StorybookStyleGuide、固定服装与信物、反复象征、章节状态检查和网页翻页转场共同保证。

本地 `storybook_motion` 是默认正式输出，不是视频失败后的降级。动效必须保留原插画构图和绘本介质，每章最多使用一个主要镜头运动与两个局部微动。允许缓慢推拉或横移、二至三层景深视差、轻微光影或雾气、环境粒子，以及呼吸、头发、衣角或信物的小幅局部运动。禁止 3D 建模、角色绑定、五官或表情变形、口型、完整走路或转身、角色三维旋转、环绕镜头、生成新人物或新剧情，以及任何明显扭曲原插画的运动。

Seedance 只提供可选的真实动态增强：

- 每章必须单独获得演示者批准后才能提交；
- 以本章主插画作为视觉参考或首帧；
- 不要求连接下一章的共享尾帧；
- 生成中、失败或质量不合格时，无条件保留已经可播放的本地 2.5D 动态预览；
- Seedance 是否完成不影响整本书达到“可开书”状态。

章节主插画必须通过人工视觉审核后才能进入本地动画。确定性技术检查仍然保留，用于尺寸、文件、编码和安全等客观问题，但不能代替插画审核，也不能自动批准 Seedance 生成。

## 结果

该方案放弃像素级共享边界和默认真实视频的运动幅度，以换取更快、更稳定的 Demo 生成、更一致的守门 IP、更完整的绘本笔触，以及不依赖视频供应商即可完成七章阅读的能力。未来若需要恢复默认真实视频，应新增 ADR，而不是重新启用本 ADR 已取代的关键帧和降级合同。
