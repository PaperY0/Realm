# 正式关键帧图像模型必须支持固定 IP 参考

V0 的正式关键帧图像模型必须支持参考图生成或图片编辑。生成 K0–K7 中的每一张边界关键帧时，都重新提供同一套内耗守门 IP 标准图和角色设定；画风参考与相邻状态图可以作为附加输入，但不能取代固定 IP 锚点。

正式关键帧不使用纯文本生图，也不通过把上一帧不断传给下一帧的方式逐章递推，以免角色误差累积。进入七章视频并行生成前，系统必须先验证角色脸型、身体比例、服装核心结构和标志性物件；不合格的关键帧需要重新生成，不能交给视频模型自行修正。

该选择限制了可用图像模型，并增加关键帧前置验证成本，但能在并行视频任务开始前固定角色视觉身份，避免错误扩散到整本绘本。
