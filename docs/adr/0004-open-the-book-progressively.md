# 在部分章节就绪后渐进式开书

系统不等待七章完整视频全部生成。完整七章故事规划冻结、第一章完整视频或经过验证的个性化降级版本可播放、第二章至少存在个性化降级版本且其余章节任务均已启动后，即允许用户打开绘本。

第一章仍优先等待完整视频；只有完整视频的一次重试失败或达到规定的等待上限后，才使用同一故事设定与章节卡生成的个性化降级版本。系统不得使用与用户经历无关的通用占位片，也不得因为第一章完整视频失败而阻断整本书。

该选择利用用户的阅读时间继续生成后续章节，并保证外部视频任务失败时仍能开始故事。系统必须为每章准备快速保底版本、控制“下一章”的可用状态，并避免在用户观看过程中热切换媒体。
