# V0 只交付 Windows 本机单实例比赛 Demo

当前交付只需在一台 Windows 演示电脑上，由浏览器和本地 Node.js 服务端使用真实模型调用完成一次七章绘本生成。体验从世界主 IP 引导用户亲手开门、走过可选称呼与口袋印记的旅人初页开始，经唯一开放的内耗之门抵达风铃入口；本次会话需求只调整题记和合书回应语气，最多两次自然追问均可跳过。确认表达后以纸船仪式承接真实故事、插画、人工审核和本地 2.5D 动效生成；逐章阅读只允许不改变剧情的视觉互动，最后完成合书、信物和环境变化。

任务和媒体保存在本机，并支持刷新或再次进入时恢复、继续和重读当前一本绘本。V0 不保存多册，也不支持在保留当前书时生成下一册；用户要讲述新经历，必须先一键重置当前书。为了把时间集中在个性化故事、七张主插画、2.5D 动态预览和网页展示上，本次不实现多书架、公网部署、账户、多用户并发、分布式队列、云对象存储、CDN、生产级高可用及商业化能力；相关产品规则保留为未来边界，但不作为 Demo 验收项。
