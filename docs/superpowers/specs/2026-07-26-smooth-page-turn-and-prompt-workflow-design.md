# 流畅翻书动画与四阶段绘本生成设计

## 目标

将当前“右页机械打开”的效果改成有纸张质感的真实翻书动画，并把绘本生成过程明确为：

1. 生成并展示总 AI Prompt；
2. 根据总 Prompt 生成七章短剧本；
3. 根据每章短剧本生成对应的 AI Image Prompt；
4. 根据每章 Image Prompt 生成七张章节插画，全部成功后进入阅读器。

绘本阅读页仍保留目录、绘本名称、章节切换和持久化能力；右页只呈现短标题、少量正文和插画，不展示冗长的内部 Prompt。

## 方案

### 1. 双层纸页翻动

翻页时保留当前 DOM 阅读页作为底层，并生成一个独立的翻页纸片。纸片包含正面和背面：

- 正面显示离开的当前页；
- 背面显示下一页的预览色面或下一页内容；
- 翻页纸片以书脊为轴，从 `rotateY(0deg)` 经过 `rotateY(-90deg)` 到 `rotateY(-178deg)`；
- 上层纸片的阴影、背面亮度和书脊阴影随进度变化；
- 上一章使用相同结构反向运动。

动画时长控制在 800ms 左右，采用分段缓动，避免匀速机械旋转。翻页期间锁定上一页、下一页按钮，动画结束移除临时纸片；减少动态设置仍然跳过运动并直接切换内容。

### 2. 四阶段生成数据

故事包增加明确的生成合同，不改变现有 `SafeStoryBrief` 安全边界：

- `storyPrompt`：根据安全摘要整理出的总 Prompt，仅保存结构化安全字段和绘本风格约束；
- `chapterCards[]`：七个章节短剧本，每章包含标题、短正文、叙事功能和画面契约；
- `chapterCards[].promptContract.imagePrompt`：该章独立的 Image Prompt；
- `chapterIllustrations[]`：每章图片状态、图片地址、错误码。

每章正文限制为适合右页阅读的短文本，生成 Prompt 可以更长，但只在生成状态面板折叠展示。服务端继续负责校验故事包和调用图片网关，浏览器不接触密钥。

### 3. 页面状态

生成面板使用明确的状态阶段：

- `prompting`：整理总 AI Prompt；
- `writing`：七章短剧本生成完成或进行中；
- `image-prompting`：为七章生成 Image Prompt；
- `illustrating`：七章图片并行生成，显示每章状态；
- `ready`：所有图片成功，允许进入绘本；
- `error`：保留失败阶段和可重试入口。

真正进入阅读器的条件是七章插画全部成功。失败时不伪造图片、不进入半成品绘本。

## 文件边界

- `src/app.js`：生成阶段状态、阶段提示、阅读器翻页触发和临时纸片管理。
- `src/styles.css`：正面/背面纸片、书脊透视、阴影和分段缓动。
- `src/domain/story-package.js`：故事 Prompt、短剧本和章节 Image Prompt 的结构化合同。
- `src/services/chapter-image-generation.js`：沿用现有七章并行图片生成器，保留并发上限、逐章状态和结果汇总；只让它读取前置阶段已经确定的每章 Image Prompt，不改成串行生成。
- `server.js`：保持安全校验，提供故事包和七章插画阶段接口。
- `src/index.html`：生成状态面板和章节 Prompt 的折叠展示结构。

## 验收标准

### 翻页

- 点击下一章时，右页先从右侧掀起，经过书脊后落到左侧；不是整张页面瞬间绕轴打开。
- 动画中间帧能看到纸片背面、书脊阴影和非线性的角度变化。
- 点击上一章时方向相反。
- 动画结束后临时翻页层被移除，章节编号和正文正确更新。
- 键盘操作、目录和减少动态模式不回归。

### 生成流程

- 页面能依次显示总 AI Prompt、七章短剧本、七章 Image Prompt 和插画生成状态。
- 每章右页文字短小，图片和章节对应。
- 七章图片未全部成功时不能进入阅读器；现有 `chapter-image-generation.js` 的并行任务和逐章失败状态继续作为唯一图片生成入口。
- 生成失败可重试，且不会泄露原始表达或模型密钥。

### 验证

- 运行 `node --check src/app.js`、`node --check server.js` 和完整 `npm test`。
- 在浏览器中验收翻页的 100ms、400ms 和结束状态；确认中间帧存在非 identity 的 3D transform。
- 在浏览器中走完生成状态面板，确认七章短剧本、Image Prompt 状态和插画结果可见。
