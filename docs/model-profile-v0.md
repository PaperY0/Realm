# V0 模型配置档案

> 状态：已锁定。模型通过统一模型网关调用；不进行多模型定标或运行时自动路由。

## 接入边界

- `TEXT_BASE_URL`：`https://api.openai-next.com/v1`
- `MEDIA_BASE_URL`：`https://draw.openai-next.com`
- 认证：一个服务端环境变量提供的 API Key，禁止进入浏览器包、日志或仓库。

## 固定模型

| 能力 | 配置项 | 模型 | 状态 |
|---|---|---|---|
| 文本 | `TEXT_MODEL` | `gpt-5.6-sol` | Accepted |
| 图像 | `IMAGE_MODEL` | `gpt-image-2` | Accepted |
| 视频 | `VIDEO_MODEL` | `doubao-seedance-2-0-fast-260128` | Accepted |

## 图像模型准入要求

- 必须支持参考图生成或图像编辑。
- K0–K7 每张关键帧都重新提供固定的内耗守门 IP 参考。
- 允许补充画风图和相邻状态图，但不得采用纯文本生图作为正式关键帧。
- 正式关键帧成品统一为 1280×720、16:9；构图遵守桌面端安全构图区。

## 视频模型准入要求

- 必须原生支持首尾帧输入。
- 不支持尾帧约束的模型不得生成正式章节视频。
- 供应商原始输出不直接发布，由服务端 FFmpeg 标准化后再进入自动媒体验收。

## 文本模型准入要求

- 所有工作流输出必须通过应用层 Schema 校验。
- 首次格式错误只允许一次受限格式修复。

## 章节视频规格

- 每章一个约 5 秒的 16:9 连续镜头。
- 章内不切镜，只包含一个主要动作和一次主要镜头运动。
- 七章共生成七个正式章节视频。
- 视频结束后停在稳定尾帧，等待用户主动进入下一章。
- 发布规格统一为 1280×720、24 fps、MP4 / H.264 / yuv420p、无音轨。
- 完整视频与 `dynamic_fallback` 使用同一 16:9 网页容器，不显示浏览器原生视频控件。
- 完整媒体技术合同见 `docs/media-profile-v0.md`。
