# 下一章插画双面翻页设计

## 目标

修正阅读器前翻时纸张背面出现镜像文字的问题，使其在整个翻转过程中显示下一章的插画页，形成可辨认的实体书翻页效果。

## 已确认交互

- 点击“下一章”时，右侧当前章插画页从书脊翻向左侧。
- 临时纸张正面渲染离开章节的插画；背面预先渲染下一章插画，且背面内容不会使用文字页克隆或 CSS 镜像。
- 纸张使用约 840ms 的分段 3D 转动，配合书脊阴影、背面亮度变化和非线性缓动。
- 动画期间目录及前后翻页操作保持单次锁定；结束时移除临时层并显示下一章完整跨页。
- 后翻维持现有反向运动语义；本次不改动故事生成、章节数据和未提交的背景样式。

## 实现边界

- `src/app.js`：显式为前翻建立“当前插画正面 / 下一章插画背面”临时面，动画后清理。
- `src/styles.css`：仅调整翻页层的面向、可见性、阴影和层级，确保背面在过书脊后正确朝向读者。
- `tests/stage13-web-storybook.test.js`：先新增静态/行为断言，证明下一章插画被绑定到背面，避免回归为文本页或镜像面。

## 验收

1. 前翻中段不出现反向文字。
2. 前翻纸背可见下一章的章节插画。
3. 动画结束后章节标题、正文和插画一致，临时翻页层不存在。
4. 快速连续点击只推进一章，完整测试和浏览器中间帧检查通过。
