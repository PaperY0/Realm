# 《藏梦书境》五个情绪入口守门 IP 设计

> 日期：2026-07-25
> 状态：FINAL CHARACTER AUTHORITY｜五个情绪守门 IP 唯一角色设定源
> 画风权威：`assets/bible/STYLE-BIBLE.md` V3.3
> 角色类型：书境造物家族；原创非动物、非人类小守门者

## 1. 目标

为内耗、悲伤、焦虑、愤怒、喜悦五个情绪世界建立长期守门 IP。五个角色必须属于同一视觉家族，但在剪影、主色、象征物和动作语言上不可互换。它们不是心理类型标签，不诊断用户，也不承担世界主 IP 或卷内故事主角的职责。

## 2. 家族不变量

- 约 1.3–1.6 头身，矮小圆润；
- 点状眼睛、极小嘴形和克制腮红；
- 连贯完整的暖棕褐彩铅主轮廓；
- 细腻、均匀、柔软的中饱和水彩；
- 一个主体轮廓、1–3 个主要色块、少量内部线；
- 左下侧保留一个暖白书页折角家族标记；
- 不使用动物耳朵、尾巴、毛发、翅膀或人类服装；
- 情绪通过姿态、距离和道具表达，不使用夸张动漫表情；
- 正面、侧面和背面均可由剪影与核心配件识别。

## 3. 五个角色

### 3.1 内耗之门｜绾线

- 原型：折页线轴种子；顶部为向内弯曲的低折痕；胸前有一个松线结；背后露短线尾。
- 主色：暖纸杏白；灰紫线；橄榄绿小配件；少量珊瑚红结点。
- 性格：谨慎、认真、不催促。
- 常态：护住胸前线结。
- 靠近：把线结藏到身后，只露线头。
- 进入：把线递给旅人，沿线走入门内并回头等待。

### 3.2 悲伤之门｜听雨

- 原型：圆润折页蓄水器；顶部是一片向下弯曲的宽叶檐；手持小叶碟；腹部有浅水面色块。
- 主色：雾蓝；灰紫；鼠尾草绿；少量灰粉和奶白。
- 性格：安静、容纳、不急着擦掉眼泪。
- 常态：听叶檐上的雨滴。
- 靠近：用叶碟接住一滴水。
- 进入：把水滴倒进小水洼，水面开出一朵小花。

### 3.3 焦虑之门｜息摆

- 原型：一叠圆角小纸签形成的身体；顶部一根柔软短风标；一侧垂三张纸签；腹部有小摆珠。
- 主色：灰青；浅紫；淡杏黄；珊瑚橙摆珠。
- 性格：敏锐、忙碌，但愿意陪伴寻找节奏。
- 常态：纸签以不同节奏摆动。
- 靠近：双手护住摆珠，纸签逐渐同步。
- 进入：呼吸一次，让纸签依次停下并推门。

### 3.4 愤怒之门｜藏烬

- 原型：圆钝炭火种壳；顶部有一道柔和裂口；胸前有半透明小灯窗与单颗火种；下宽上窄。
- 主色：焦糖棕；砖红；可可深棕；暖橙和少量金黄。
- 性格：稳、直接、有边界，不要求熄灭火焰。
- 常态：双手挡在灯窗前。
- 靠近：打开一条通风缝，让火焰稳定。
- 进入：把灯窗转向门内，使火光成为路径。

### 3.5 喜悦之门｜铃芽

- 原型：圆润铃花种子；顶部一片弯曲嫩芽；侧面垂一朵小铃花；腹部有浅色花瓣区。
- 主色：蜜糖黄；嫩芽绿；莓粉；奶白和少量杏橙。
- 性格：轻盈但不喧闹，善于记住小小的好事。
- 常态：捧着未开放的小铃花。
- 靠近：铃花慢慢打开，只响一声。
- 进入：把发亮小种子放入门边土壤，安静邀请旅人同行。
