# 风铃入口水彩纸张质感设计

## 目标

在不改变“风铃入口 / 写信”页面交互和内容结构的前提下，将页面视觉调整为多色水彩绘画背景，并让中央信纸具备轻微、自然的褶皱和纸张层次。

## 视觉方案

- 复用项目已有的 `expression-watercolor-reference.png` 水彩背景，保持 V3.3 的多色水彩、暖纸留白和柔和层次。
- 使用 CSS 伪元素在中央信纸上叠加局部色彩渗透、折痕、高光和不规则边缘，不新增完整纸张背景图。
- 褶皱保持低对比度、局部可见，避免粗糙噪点、厚重 3D 纸张或影响文字阅读。
- 保留现有表单、按钮、演示句、追问和生成流程，仅调整背景、信纸及控件材质。

## 响应式与验证

- 桌面端保持参考图的居中横向信纸构图。
- 移动端保持纵向可滚动布局，褶皱与背景不遮挡输入内容。
- 通过现有测试、语法检查和本地页面检查确认交互未被样式改动破坏。
