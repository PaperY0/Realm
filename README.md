# 藏梦书境

> 一个把心事写成童话的世界。

《藏梦书境》是一个 Windows 本机单实例互动 Web Demo：用户进入唯一开放的“内耗世界”，自然表达一次经历，系统通过真实文本与图像模型生成完整七章故事和七张章节主插画，并以网页翻书和本地 2.5D 动态预览完成阅读、合书与入架闭环。

## V0 边界

### 必须形成的闭环

1. 在 Chrome 或 Edge 全屏进入唯一开放的内耗世界。
2. 用户自然表达，可跳过最多两次追问；系统完成安全分流和隐私过滤。
3. 真实生成并校验 SafeStoryBrief、内部路由、故事事实、视觉合同与恰好七张 ChapterCard。
4. 并行生成七张 9:16 章节主插画，逐章人工审核；失败只重做对应章节。
5. 用审核通过的插画制作七章本地 2.5D 动态预览；它是默认正式章节媒体。
6. 七章资产全部通过门禁后，在最长 5 分钟开书窗口内进入真实翻书阅读。
7. 完成合书、信物、世界变化、入架、刷新恢复、重读和一键重置。

### 运行约束

- Windows 演示电脑，本地浏览器 + 本地 Node.js 服务端。
- 一次只有一名用户、一个浏览器会话、一本当前绘本。
- 使用真实文本和图像模型；不得用预生成故事或插画冒充本次结果。
- SQLite 保存状态和相对路径，媒体文件按当前 `bookId` 存放在本地磁盘，不写为数据库 BLOB。
- API Key 只存在于服务端环境变量，不进入浏览器包、数据库、日志或仓库。
- Seedance 仅为逐章人工批准后的可选增强，不影响开书，不属于 V0 闭环成功条件。

### 明确不做

- 其他情绪世界、多世界选择、用户选故事卷或第三套内耗故事卷。
- 注册登录、跨设备同步、多用户并发、多册书库或不重置直接生成下一册。
- 公网部署、云存储、队列、高可用、生产监控、支付和运营后台。
- 剧情分支、自由 3D 探索、3D 角色表演、AI 配音或默认视频模型生成。
- 移动端完整适配；手机和平板只要求页面不崩溃。
